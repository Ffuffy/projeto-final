# projeto-final
🐍 Jogo da Cobrinha (Snake Game)
🎮 Sobre o Projeto
Este é um projeto que recria o clássico e viciante "Jogo da Cobrinha", popularizado nos antigos celulares. O objetivo principal foi desenvolver um jogo funcional que demonstra a aplicação de conceitos fundamentais de programação, como lógica de movimentação, detecção de colisão, manipulação de estados de jogo e renderização dinâmica.
O projeto foi uma excelente oportunidade para aprofundar conhecimentos em [mencione a tecnologia, ex: Python com Pygame, JavaScript com Canvas], e entender a dinâmica por trás da criação de jogos simples.
✨ Funcionalidades
Gameplay Clássico: Controles simples para mover a cobrinha e coletar comida.
Aumento de Pontuação: A cada comida coletada, a pontuação aumenta e a cobrinha cresce.
Detecção de Colisão: O jogo termina quando a cobrinha colide com as paredes ou com o próprio corpo.
Interface Clara: Uma interface minimalista e funcional que foca na jogabilidade.
Reinício do Jogo: Opção para começar um novo jogo após o Game Over.
